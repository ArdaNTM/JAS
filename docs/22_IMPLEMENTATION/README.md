# Engineering implementation ledger

This directory holds the **117-feature engineering program**, subordinate to the established JAS architectural specifications in `docs/00_VISION` through `docs/21_BENCHMARKS`.

- [Implementation plan](AURA_MASTER_IMPLEMENTATION_PLAN.md)
- [Machine-readable tracker](AURA_FEATURE_TRACKER.json)
- [Implementation log](AURA_IMPLEMENTATION_LOG.md)
- [Blockers](AURA_BLOCKERS.md)
- [Test report](AURA_TEST_REPORT.md)
- [Architecture decisions](AURA_ARCHITECTURE_DECISIONS.md)

Validate locally with `python scripts/validate_aura_feature_tracker.py`. New feature claims start unverified until the actual JAS source, integration, test, license and hardware evidence is reviewed. This ledger is not an activation mechanism.
